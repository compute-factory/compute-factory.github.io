# 资料架

选一项正在做的任务，再找对应的阅读资料。入门阶段可以先完成一份实验记录，遇到具体问题时再查文档。

| 资料 | 适合什么时候看 |
| --- | --- |
| [PyTorch 入门教程](https://pytorch.org/tutorials/beginner/basics/intro.html) | 第一次接触张量、模型和训练循环时。 |
| [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1) | 认识 Transformer、tokenizer 和预训练模型时。 |
| [CUDA 编程指南](https://docs.nvidia.com/cuda/cuda-programming-guide/) | 准备了解线程、内存和 GPU 执行模型时。 |
| [WSJ 的 AI Infra 笔记](https://wsj040303.github.io/ai-infra/) | 已经知道想了解哪个主题，准备读算子、推理框架或论文时。 |

## 推荐项目 {#recommended}

**llama.cpp** 适合希望在自己电脑上跑通大模型推理的读者。可以先运行一次文本生成，记录模型、硬件和生成速度，再尝试改变输入长度。安装和运行步骤以项目维护者的文档为准。 [官方仓库](https://github.com/ggml-org/llama.cpp)

想补充资料时，可以在 [GitHub 仓库](https://github.com/compute-factory/compute-factory.github.io) 提交 PR，附上原始链接、适合的读者和阅读前需要掌握的知识。
