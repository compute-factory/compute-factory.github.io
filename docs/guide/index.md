# 学习路线

AI Infra 关注模型背后的系统。一次请求从进入服务，到变成 token，再到占用内存和执行计算，中间每一步都可以测量和优化。先走通一次请求，再按遇到的问题选择更深的方向。

| 阶段 | 要回答的问题 | 动手目标 |
| --- | --- | --- |
| 01 · 模型怎么装进去 | 参数量和数据类型如何影响内存？ | 完成[第一张工单](./first-lab)，算出不同精度下的权重大小。 |
| 02 · 模型怎么生成文本 | 输入如何变成 token？为什么输出是逐步生成的？ | 跑通一次本地推理，改变输入长度和生成上限，记录输出。 |
| 03 · 服务怎么接请求 | 延迟、吞吐和并发怎么衡量？ | 对同一模型改变请求并发，比较首 token 延迟与输出速度。 |
| 04 · 系统为什么变快 | 算子、显存带宽、缓存和多卡通信各卡在哪里？ | 从一次可复现的性能测试入手，再读相关实现或论文。 |

## 从哪里开始

刚接触模型部署，先做阶段 01。已经跑过本地模型，可以按阶段 02 和 03 的目标补一份实验记录。对某个工具或主题有兴趣时，去[资料架](../resources)找对应的阅读入口。
